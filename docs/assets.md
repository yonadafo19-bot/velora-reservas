# Activos visuales — Fase 1

## Estado actual

La Fase 1 no incorpora fotografías de terceros ni logotipos de negocios reales.

Las composiciones de Velora Barbería y Velora Belleza usan exclusivamente:

- gradientes CSS;
- formas geométricas CSS;
- iniciales de perfiles ficticios;
- el wordmark tipográfico provisional “Velora Reservas”;
- iconos SVG originales, dibujados como trazos simples dentro del código.

Por lo tanto, no existen atribuciones externas ni licencias de imágenes pendientes en esta versión.

## Incorporación futura de fotografías

Antes de agregar una fotografía se debe registrar aquí:

1. nombre del archivo local;
2. autor o proveedor;
3. URL de origen;
4. tipo de licencia;
5. fecha de descarga;
6. alcance comercial permitido.

No se deben usar imágenes encontradas en buscadores, redes sociales o sitios de negocios sin autorización verificable.

## Identidad

“Velora Barbería” y “Velora Belleza” son conceptos ficticios creados únicamente para esta demostración comercial. El wordmark actual es provisional y no reemplaza un proceso posterior de identidad de marca.
