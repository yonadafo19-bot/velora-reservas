# Release Notes Internas

Esta carpeta guarda notas internas de release para features, fixes y bloques operativos relevantes.

Las release notes no son marketing. Son el registro de que se entiende que cambio, como se valido y como se podria revertir.

Cada nota debe incluir:

- cambio realizado;
- impacto para usuario o administrador;
- impacto tecnico;
- riesgos y limitaciones;
- QA ejecutado;
- comandos ejecutados;
- smoke manual;
- rollback sugerido;
- estado final de Git o commit asociado.

## Convencion de nombres

Usar:

```text
NNN-nombre-feature.md
```

Para fixes:

```text
fix-descripcion-corta.md
```
