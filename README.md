# Velora Reservas

Demo visual premium y mobile-first para barberías y estudios de belleza en Chile.

## Desarrollo

```bash
corepack pnpm dev
```

Abrir `http://localhost:3000`.

## Validación

```bash
corepack pnpm lint
corepack pnpm build
```

La Fase 1 funciona con datos locales ficticios. No incluye backend, autenticación, pagos, correos ni integraciones externas.
